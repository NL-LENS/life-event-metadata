
### Project goal

The goal of this repo is to create a dictionary of events occurring in
administrative datasets held in the ODISSEI Knowledge Graph.

### Knowledge graph reference

All SPARQL endpoint details, prefixes, graph structure, and example queries
are in [`skills/odissei_kg_reference.md`](skills/odissei_kg_reference.md).

### Key data files

- `data/designs-with-events_preflabel.csv` — datasets with person identifier + tijdstip variable (short labels)
- `data/data-designs-extended.csv` — same, with column names and descriptions
- `data/data-designs-without-tijdstip-with-frequency.csv` — datasets with person identifier but no tijdstip column
