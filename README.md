# teamnl-events-dataset
Repository to coordinate work around the creation of an event-based dataset in the CBS ME

# Content
Data-design-with-event_preflabel.csv is an export of a SPARQL query run on Triply (see [here](https://kg.odissei.nl/odissei/-/queries/Data-designs-with-events/3)) on the KG. It is intended to list all the CBS data designs in the Portal which contain RINPERSOON AND a variable which mentions "Tijdstip" in its metadata. The query found 818 RINPERSOON + Time combinations, from 260 datasets
